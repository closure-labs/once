# Once v0.2.0

Once v0.2.0 makes protected policy independent from candidate repository code,
packages the protected workflow as a reusable GitHub Action, and completes the
planned diagnostic and compatibility interfaces.

## Highlights

- Load policy from a separately protected flake pinned by a full GitHub commit
  and independently verify the revision reported by Nix metadata.
- Provide a reusable composite Action for `doctor`, `check`, and `run` with
  exact policy exit codes, versioned JSON output, and fail-closed defaults.
- Give `resolve`, `trace`, `trust`, and `explain` purpose-built human and v1 JSON
  diagnostics without building or downloading the requested installable.
- Lock the public JSON contracts with golden fixtures and adversarial tests for
  malformed, conflicting, untrusted, and unsupported trace states.
- Test the Nix 2.35.2 release floor from a full-commit-pinned community nixpkgs
  `nixVersions.latest` package.
- Accept upstream Nix prerelease snapshot version strings while preserving
  correct prerelease ordering in minimum-version checks.

## Protected policy

The reference policy lives in
[`closure-labs/once-policy`](https://github.com/closure-labs/once-policy). A
protected workflow must pin both the Once Action and policy flake by immutable
full commits. Candidate-controlled local TOML remains useful for development,
but it is not the protected-CI trust boundary.

## Trust boundary

Remote trace hits remain `UNSUPPORTED`. The v0.2 audit covered Nix 2.35.2 and
current upstream: internal substitution code can validate realisation
signatures, but no public read-only CLI or stable C API exposes that validation
without crossing Once's no-realisation boundary. Once continues to accept reuse
only from the trusted local store and never treats signer labels as proof.

## Install

```console
nix profile install github:closure-labs/once/v0.2.0
```

The GitHub release also contains a checksummed `x86_64-linux` archive. The
tagged flake is published to FlakeHub as `closure-labs/once/0.2.0`.
