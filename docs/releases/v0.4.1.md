# Once v0.4.1

Once v0.4.1 makes this repository the first-class source for both conventional
Nix package and flake package use. Official Nixpkgs submission remains planned
for the long term, after Once's package interfaces and security behavior have
matured.

## Highlights

- Add a pinned top-level `default.nix` so a checkout builds with `nix-build`.
- Keep the conventional package entry point on the same community Nixpkgs
  revision as `flake.lock`.
- Retain `packages.x86_64-linux.once`, the default package and app, and
  `overlays.default` for flake consumers.
- Document direct package, flake input, overlay, and NixOS installation paths.
- Use the Closure Labs GitHub repository and immutable release tags as the
  authoritative package source during early maturity.

## Build from a checkout

```console
nix-build
./result/bin/once --version
```

## Install or run the flake package

```console
nix profile install github:closure-labs/once/v0.4.1#once
nix run github:closure-labs/once/v0.4.1#once -- --help
```

See the [Nix package guide](../nix-package.md) for downstream flake, overlay,
and NixOS examples. The GitHub release also contains a checksummed
`x86_64-linux` archive.
