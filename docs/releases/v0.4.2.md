# Once v0.4.2

Once v0.4.2 adds a signed public binary cache and a reproducible devenv
environment to the repository-hosted Nix package distribution.

## Highlights

- Declare `https://once.cachix.org` as an extra flake substituter with its exact
  public signing key.
- Pull cached paths in pull-request, protected `main`, and release workflows.
- Push newly built paths only from protected `main` and release workflows using
  the repository's `CACHIX_AUTH_TOKEN`; pull requests never receive the token.
- Pin Cachix Action v17 to its immutable commit.
- Add `devenv.nix`, `devenv.yaml`, and `devenv.lock` with the same pinned
  community Nixpkgs revision and development tools as the flake shell.
- Keep local devenv use read-only with `cachix.pull = [ "once" ]`.

## Install or run

```console
nix profile install --accept-flake-config \
  github:closure-labs/once/v0.4.2#once
nix run --accept-flake-config github:closure-labs/once/v0.4.2#once -- --help
```

On multi-user Nix installations, an administrator may need to add the cache URL
and public key to the daemon configuration. See the
[Nix package guide](../nix-package.md#binary-cache) for the exact settings and
the devenv workflow.
