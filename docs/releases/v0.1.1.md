# Once v0.1.1

Once v0.1.1 hardens repository governance and distribution around the v0.1
proof of concept. It does not widen the build-trace trust boundary.

## Changes

- Use the canonical Apache-2.0 license text and record the project copyright.
- Publish tagged flakes to FlakeHub from the GitHub release workflow.
- Attach an `x86_64-linux` archive and SHA-256 checksum to each GitHub release.
- Correct the v0.1 acceptance matrix with the successful `main` CI evidence.
- Assign repository ownership to `@declarative-dale` and protect `main` through
  GitHub repository rules.

## Trust boundary

Remote trace hits remain `UNSUPPORTED` because Nix 2.35 build-trace inspection
does not validate their signatures. This release continues to recognize traces
only through the trusted local-store boundary documented for v0.1.0.
