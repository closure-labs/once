# Once v0.4.0

Once v0.4.0 packages the project as a reusable Nix package and overlay served
directly from the Closure Labs GitHub repository. It uses the community
Nixpkgs upstream as its package set. Official Nixpkgs submission is deferred
until Once has matured; this repository is the authoritative package source for
v0.4.0.

## Highlights

- Provide `nix/package.nix` as a standard `callPackage`-compatible Rust package.
- Export `overlays.default` so downstream flakes can add `pkgs.once` without
  duplicating the derivation.
- Validate `once --version` as part of the Nix install check.
- Advertise the repository-hosted package on supported Linux platforms through
  standard Nix package metadata.
- Pin the project development environment directly to the community
  `NixOS/nixpkgs` upstream.

## Install

Install the tagged flake package:

```console
nix profile install github:closure-labs/once/v0.4.0#once
```

## Use as a Nixpkgs overlay

```nix
{
  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixpkgs-unstable";
    once.url = "github:closure-labs/once/v0.4.0";
    once.inputs.nixpkgs.follows = "nixpkgs";
  };

  outputs = { nixpkgs, once, ... }:
    let
      system = "x86_64-linux";
      pkgs = import nixpkgs {
        inherit system;
        overlays = [ once.overlays.default ];
      };
    in {
      packages.${system}.default = pkgs.once;
    };
}
```

The overlay exposes `once` through the downstream Nixpkgs package set. The
GitHub repository and tagged revisions are the authoritative Nix package
source. See the [Nix package guide](../nix-package.md) for direct package,
downstream flake, and NixOS examples. The GitHub release workflow also produces
a checksummed `x86_64-linux` archive.
