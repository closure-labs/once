# Once v0.3.0

Once v0.3.0 adds reproducible evidence for Nix 2.35.2 and a pinned 2.36
prerelease, then packages successful evidence as independently verifiable
deterministic signed JSON.

## Highlights

- Reproduce accepted- and unrelated-key substitution behavior against isolated
  Nix 2.35.2 and 2.36 prerelease stores.
- Confirm that 2.36 rejects an unrelated build-trace key during substitution
  while the read-only trace interface remains unverified in both versions.
- Emit matrix evidence as a canonical `dev.closurelabs.det/v1` `.det` artifact
  signed with Ed25519.
- Verify `.det` integrity and authorize signer identity against an independently
  pinned public key.
- Reject noncanonical, malformed, tampered, oversized, symlinked, or
  unauthorized artifacts and unsafe signing-key permissions.

## Deterministic artifacts

The `.det` envelope signs the canonical matrix payload using DSSE v1
pre-authentication encoding. The embedded public key makes an artifact
self-checking; an external public-key pin is still required to authorize the
signer. The format records evidence from the controlled substitution
experiment and does not make Nix's read-only trace response verified.

See the [deterministic artifact guide](../deterministic-artifacts.md) and
[Nix version proof](../planning/nix-2.35-2.36-build-trace-proof.md) for the
format, operational controls, exact revisions, and reproduction steps.

## Trust boundary

Remote trace hits remain `UNSUPPORTED`. Nix 2.36's unrelated-key rejection is
inside substitution, which crosses Once's no-realisation boundary. Once still
accepts reuse only from the trusted local store and never treats an unverified
signer label or a self-contained public key as authorization.

## Install

After the v0.3.0 tag is published:

```console
nix profile install github:closure-labs/once/v0.3.0
```

The GitHub release workflow produces a checksummed `x86_64-linux` archive and
publishes the tagged flake to FlakeHub as `closure-labs/once/0.3.0`.
