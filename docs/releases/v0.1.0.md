# Once v0.1.0

Once v0.1.0 is the first proof-of-concept release of Closure Labs' “build
once, recognize thereafter” experiment for Nix.

## Highlights

- `once doctor` verifies the Nix version and required experimental features.
- `once check` resolves and inspects a Nix 2.35 build trace without
  intentionally building the requested installable.
- `once run` builds only after a miss and then requires the resulting trace to
  satisfy local policy.
- Human-readable and versioned JSON output distinguish accepted results,
  misses, policy failures, conflicts, unsupported environments, configuration
  errors, and internal failures.
- The included disposable-store demo proves cold-miss/build/reuse behavior,
  reuse after deleting the expensive output, and invalidation semantics.

## Trust boundary

A successful check is a policy decision to accept a signed build-trace claim;
it is not an independent proof that arbitrary computation occurred. Nix 2.35
does not validate signatures returned by remote build-trace inspection, so this
release accepts trace reuse only from a trusted local store. Remote trace hits
fail closed as `UNSUPPORTED`.

## Requirements

- `x86_64-linux`
- Nix 2.35 or newer
- `nix-command`, flakes, and content-addressed derivations

## Try it

```console
nix develop
cargo build
./target/debug/once doctor
./scripts/demo.sh
```
