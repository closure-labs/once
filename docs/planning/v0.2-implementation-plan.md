# Once v0.2 implementation plan

Work proceeds in the milestone order tracked on GitHub:

1. Load trust policy from an immutable, separately protected flake.
2. Package the protected invocation as a reusable GitHub Action.
3. Give `resolve`, `trace`, `trust`, and `explain` distinct diagnostics.
4. Add command-specific integration and JSON compatibility tests.
5. Re-evaluate upstream Nix support for safe remote trace validation.

The first phase is complete only when a real protected policy repository can be
resolved by full commit, its revision mismatch fails closed, and mutable policy
references never reach target evaluation.

The second phase is complete only when the Action builds Once from its own
pinned source revision, accepts no arbitrary command arguments, preserves the
versioned JSON and exact CLI exit code, fails on nonzero results by default, and
documents the separate risks of `check` and `run` for untrusted pull requests.

The third phase is complete only when each diagnostic has focused human and
JSON output, all views retain the shared decision and exit-code semantics, and
no diagnostic command builds the requested installable.
